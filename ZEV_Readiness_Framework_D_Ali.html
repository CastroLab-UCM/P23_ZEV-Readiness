ZEV Readiness Framework Dashboard

This dashboard helps communities evaluate their readiness for Zero-Emission Vehicle (ZEV) adoption across six key categories: infrastructure, mobility access, supportive policies, outreach, workforce, and equity.

Score each indicator, view overall readiness results, and identify areas that need improvement. The framework supports planning, discussion, and decision-making by highlighting strengths, gaps, and opportunities. Scroll to the 📋 Scoring Table or 🔧 What to Work on Next for priority-based improvement recommendations.

How to Use This Dashboard
1
Browse the Indicator Cards
Each card represents one measurable aspect of ZEV readiness — such as charging infrastructure, workforce training, or equity access. Read the short description to understand what that indicator is measuring in your community.
2
Check the Suggested Unit & Range
Each card shows a Suggested Unit — the real-world metric used for that indicator (e.g., EVs/public port, % uptime, permit days) — and a Suggested Range with literature-backed benchmarks. Use these to understand where your community currently stands before entering a value.
3
Enter a Value — Three Easy Ways
Option A — Quick buttons: Click Not Ready, Somewhat Ready, or Ready — each button shows the real-world threshold for that indicator (e.g., ≤10 EVs/port for Ready). The value updates automatically.

Option B — Slider or number input: Drag the slider or type a precise value directly into the number box using the indicator's own unit. Use "Show readiness conditions" on each card to see what qualifies as Not Ready, Somewhat Ready, or Ready with specific real-world thresholds.

Option C — Skip unavailable data: Turn an indicator or individual sub-metric Off when reliable data are unavailable. Skipped inputs are marked “Not included” and are completely removed from indicator, category, overall, recommendation, and export calculations.
4
Read the Readiness Summary
The Overall Readiness Summary panel updates live as you enter values. Since each indicator uses a different unit, the summary converts everything to a common 0–100% readiness scale (Not Ready = 0–30%, Somewhat Ready = 30–70%, Ready = 70–100%). The Category Scores bars reveal which of the six categories are strongest and which need the most attention.
5
Review What to Work on Next
Scroll down to the "What to Work on Next" section. For every indicator it shows your current real-world value, a specific target to reach the next readiness level (e.g., "Target for Ready: Below 10 EVs/public port"), and a plain-language action step. This is your practical, prioritised to-do list.
6
Export or Print Your Results
Use the toolbar at the top to save your work:
📥 Export CSV — downloads a spreadsheet you can open in Excel or Google Sheets, with all scores in one table.
🖨 Print / Save PDF — opens your browser's print dialog. Select "Save as PDF" to create a shareable report.
💡 Tip — Use the Search & Filter bar
Use the bar at the top of the page to search by keyword (e.g. "charging" or "equity"), or filter by category or measurement type to focus on a specific set of indicators. The summary scores always reflect only the currently visible indicators.

Indicator Scoring Cards

Each indicator includes a short description, suggested unit, suggested working range, and a dynamic readiness scale based on real-world metrics. Users can adjust values using the slider or type a precise number directly into the input box — each indicator uses its own unit (e.g., EVs/port, % uptime, permit days). Community members can also select a readiness level using the quick criteria buttons, which automatically set an appropriate real-world value. Click "Show readiness conditions" inside any indicator card to see the specific thresholds for Not Ready, Somewhat Ready, and Ready before making a selection.
  • Not Ready: Use this when the file indicates no relevant actions, no systems in place, no documented planning, or no supporting evidence.
  • Somewhat Ready: Use this when some actions are underway, monitoring is partial, coverage is incomplete, or planning exists but is not yet comprehensive.
  • Ready: Use this when the indicator meets the strongest condition in the file, with consistent implementation, complete coverage, public documentation, or integration into plans.
